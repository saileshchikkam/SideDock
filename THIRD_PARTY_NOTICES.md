# Third-party software shipped with SideDock

SideDock is MIT-licensed. Its optional OCR workflow is implemented using
[Tesseract OCR](https://github.com/tesseract-ocr/tesseract), a third-party
project under the Apache License, Version 2.0, and an English language model
from the Tesseract tessdata distribution. Tesseract and its underlying image
processing libraries retain their own copyright and license terms.

The Windows installer and portable executable bundle Tesseract for offline
text recognition. No OCR image or text is sent to a remote service.

See the upstream [Tesseract LICENSE](https://github.com/tesseract-ocr/tesseract/blob/main/LICENSE)
and [Tesseract tessdata](https://github.com/tesseract-ocr/tessdata) project
for detailed attribution, licenses, and source code. Retain the applicable
third-party notices when redistributing builds.
